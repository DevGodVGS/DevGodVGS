## About Me

I'm a Full Stack Software Engineer focused on building high-performance applications, scalable backend systems, and AI-powered products.

I enjoy working across the entire engineering lifecycle, from designing intuitive user interfaces and architecting backend services to deploying secure cloud infrastructure and integrating intelligent AI capabilities.

My engineering philosophy revolves around **clean architecture, maintainability, performance, security, and meaningful user experiences.**

- Integrated LLM capabilities into real-world workflows using Azure OpenAI and Google Gemini.
- Led and mentored frontend engineers while establishing code-review and engineering standards.
- Built and experimented with independent products, automation tools, and AI-powered applications.
